## Principios que se comprueban siempre

1. Usar fuente primaria y recuperable cuando sea posible.
2. Preferir paráfrasis fiel a una acumulación de citas textuales.
3. Toda idea, dato, definición, imagen o tabla ajena necesita la atribución apropiada.
4. Cita y referencia deben corresponder exactamente en autor, fecha y sufijo del año.
5. No se referencia una comunicación personal no recuperable; sí se cita dentro del texto.
6. Para una obra recuperable, usa la versión publicada o estable disponible; no presentes una fuente secundaria como si fuera la primaria.
7. Las fuentes de clase o intranet solo entran en referencias si el lector puede recuperarlas; de otro modo se tratan como comunicación personal o se consulta la regla del curso.

## Citas en texto

| Situación | Modelo |
| --- | --- |
| Paráfrasis parentética | `(Apellido, 2024)` |
| Paráfrasis narrativa | `Apellido (2024) sostiene que ...` |
| Cita textual corta | “texto exacto” `(Apellido, 2024, p. 15).` |
| Cita textual de varias páginas | “texto” `(Apellido, 2024, pp. 15-16).` |
| Bloque de 40+ palabras | Bloque con sangría de 1,27 cm, sin comillas; punto antes de `(Apellido, 2024, p. 15)` |
| Sin páginas | `(Apellido, 2024, párr. 4)` o sección/encabezado verificable |
| Dos autores | `Apellido y Apellido (2024)`; `(Apellido & Apellido, 2024)` |
| Tres o más autores | `Apellido et al. (2024)`; `(Apellido et al., 2024)` |
| Autor corporativo | `(Organización, 2024)`; la primera mención puede introducir una sigla útil |
| Sin autor | `("Título abreviado", 2024)` para artículo/página; título en cursiva para obra independiente |
| Sin fecha | `(Apellido, s. f.)` |
| Dos fuentes en un paréntesis | `(Apellido, 2020; Apellido, 2024)` en orden alfabético |
| Mismo autor, años distintos | `(Apellido, 2019, 2024)` |
| Mismo autor y año | `(Apellido, 2024a, 2024b)` |
| Fuente secundaria | `(Autor original, 2000, como se cita en Autor secundario, 2024)` |
| Comunicación personal | `(A. Apellido, comunicación personal, 5 de septiembre de 2026)` |

La guía UPC recomienda el uso moderado de citas secundarias: registra en referencias solo la fuente secundaria leída.

Antes de dar una cita textual, pide o verifica un localizador. Si no hay páginas, utiliza un párrafo, sección, tabla, figura o marca de tiempo que realmente exista. No inventes el localizador.

## Estructuras de referencias frecuentes

Usa cursiva donde se indica mediante asteriscos. Ajusta mayúsculas, edición, número y URL únicamente si constan en la fuente.

| Tipo | Modelo |
| --- | --- |
| Libro | `Apellido, A. A. (Año). *Título del libro*. Editorial. URL/DOI` |
| Libro con edición | `Apellido, A. A. (Año). *Título del libro* (2.ª ed.). Editorial.` |
| Capítulo de libro editado | `Apellido, A. A. (Año). Título del capítulo. En A. Editor (Ed.), *Título del libro* (pp. xx-xx). Editorial.` |
| Artículo científico | `Apellido, A. A., y Apellido, B. B. (Año). Título del artículo. *Revista, volumen*(número), xx-xx. https://doi.org/xxxxx` |
| Artículo con eLocator | `Apellido, A. A. (Año). Título. *Revista, volumen*, Artículo e12345. DOI` |
| Página web | `Autor o entidad. (Año, día de mes). *Título de la página*. Nombre del sitio. URL` |
| Página web, autor = sitio | `Entidad. (Año, día de mes). *Título de la página*. URL` |
| Informe | `Entidad o Apellido, A. A. (Año). *Título del informe* (N.º de informe xxx). Editorial/Entidad. URL` |
| Tesis en repositorio | `Apellido, A. A. (Año). *Título* [Tesis de licenciatura/maestría/doctoral, Universidad]. Repositorio. URL` |
| Artículo de periódico en línea | `Apellido, A. A. (Año, día de mes). Título. *Periódico*. URL` |
| Video de YouTube | `Autor, A. A. [Canal]. (Año, día de mes). *Título* [Video]. YouTube. URL` |
| Webinar recuperable | `Autor/Entidad. (Año, día de mes). *Título* [Seminario web grabado]. Plataforma. URL` |
| Podcast | `Apellido, A. A. (Host). (Año, día de mes). Título del episodio (N.º de episodio) [Episodio de pódcast]. En *Título del pódcast*. Productora. URL` |
| Publicación en red social | `Autor [@usuario]. (Año, día de mes). Contenido hasta las primeras 20 palabras [Tipo de publicación]. Red. URL` |
| Software/app | `Autor o entidad. (Año). *Nombre* (Versión) [Software móvil/de computadora]. Editor/Tienda. URL` |

## Datos incompletos

- Autor ausente: empieza por el título.
- Fecha ausente: usa `(s. f.)` cuando no se puede recuperar; busca primero dentro del documento, metadatos o registro editorial.
- Título ausente: usa una descripción entre corchetes, por ejemplo, `[Fotografía de ...]`.
- Fuente ausente: no sustituyas información perdida con una conjetura. Busca otra fuente o entrega una referencia provisional marcada.

## Controles de la lista de referencias

- Construye cada entrada a partir de cuatro elementos: autor, fecha, título y fuente. El tipo de obra determina qué datos acompañan a cada elemento.
- Autor corporativo: escribe el nombre completo en la lista de referencias; una abreviatura puede introducirse solo cuando ayude en las citas del texto.
- La lista final es una lista de las obras citadas, no una bibliografía general, salvo que la consigna pida expresamente una bibliografía anotada.
- Mantén coincidencia exacta entre cita y referencia: mismo autor, año y sufijo `a`, `b`, etc. Las obras sin cita no se agregan por relleno.
- Conserva DOI como enlace `https://doi.org/...` cuando exista. No agregues una fecha de recuperación salvo contenido diseñado para cambiar con el tiempo.

## Formato y presentación

- Las referencias van a doble espacio, en orden alfabético, con sangría francesa de 1,27 cm.
- En los trabajos estudiantiles, confirma la plantilla del curso. Como base: papel carta, doble espacio, margen según consigna/APA, texto alineado a la izquierda, primera línea de párrafos a 1,27 cm y página arriba a la derecha.
- APA 7 admite varias fuentes legibles (por ejemplo, Calibri 11, Arial 11, Times New Roman 12, Georgia 11 o Lucida Sans Unicode 10). No fuerces una si el curso especifica otra.
- No agregues ciudad de publicación a libros APA 7.
- Para referencias con hasta 20 autores, inclúyelos todos. Con 21 o más, incluye 19, puntos suspensivos y el último autor.
- Incluye fecha de recuperación únicamente para contenido que cambia con el tiempo y no tiene versión archivada estable.

## Límites de la ficha

No cubre todas las fuentes posibles ni resuelve por sí sola legislación peruana. En esos casos, usa la guía UPC y la autoridad jurídica o editorial correspondiente; reporta la fuente y la regla utilizada.
