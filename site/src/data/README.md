# Datos editoriales de fuentes externas

`profematch-excerpts.json` contiene comentarios y metadatos atribuidos a ProfeMatch,
recogidos de las URL indicadas en cada registro. Los textos son de terceros y no
se ofrecen bajo la licencia del código de Campus. No se concede aquí una licencia
adicional de reutilización. La base y el procedimiento de integración se describen
en `docs/profematch-excerpts.md` en la raíz del repositorio.
