Blackboard MCP · Campus

Tu Blackboard UPC, disponible para tu asistente de IA.

Blackboard MCP conecta tu campus virtual con asistentes compatibles con Model Context Protocol. Pregunta por tus cursos, tareas, notas y anuncios sin buscar manualmente entre pestañas.

¿Qué puedes hacer?

  • Ver tus cursos y próximos vencimientos.
  • Consultar calificaciones con el contexto de cada actividad.
  • Revisar anuncios y materiales publicados.
  • Preguntar en lenguaje natural desde ChatGPT, Claude u otro cliente MCP.

¿Cómo funciona?

Conectas tu cuenta una vez. Campus mantiene una sesión separada y revocable para consultar Blackboard UPC y devolver respuestas útiles a tu asistente. Tu campus institucional continúa siendo la fuente oficial.

Hecho para estudiantes UPC

A diferencia de una integración genérica de Blackboard, Campus empieza por el flujo real del estudiante: tareas pendientes, fechas y notas que necesitas revisar durante la semana. Ese flujo está descrito paso a paso en la guía para organizar tu semana en Blackboard sin perder fechas. Si usas Gemini, sigue el tutorial de Gemini Spark MCP para conectar Blackboard UPC. Si prefieres trabajar desde la consola en vez de desde un asistente, la misma información está disponible en Blackboard CLI, el cliente de terminal de Campus.

Cómo conectarlo, según tu asistente

Antes de elegir guía, hay una bifurcación que decide todo: si usas ChatGPT o Claude en el navegador o en el móvil, esos chats no pueden ejecutar un programa en tu computadora y necesitan conectarse a un servidor. Esa es la versión de Campus que no instalas.

Si trabajas en un editor de escritorio, sigue leyendo: ahí el conector corre en tu propia máquina y es gratis. Los pasos cambian un poco en cada cliente, así que hay una guía por cada uno.

  • Claude Desktop
  • Claude Code
  • Cursor
  • GitHub Copilot en VS Code
  • OpenAI Codex CLI
  • Windsurf

Y si todavía estás decidiendo, la comparativa de servidores MCP para Blackboard explica qué opciones existen y en qué se diferencian.

Preguntas frecuentes

¿Qué es Blackboard MCP?

Es una forma estándar de exponer herramientas de Blackboard a un asistente de IA mediante Model Context Protocol.

¿Campus está afiliado a Blackboard o UPC?

No. Campus es un proyecto independiente compatible hoy con Blackboard UPC.
