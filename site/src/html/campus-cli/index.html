Preguntas directas

Antes de conectar.

Lo esencial sobre acceso, compatibilidad y control de tu cuenta.

¿Cómo analiza Campus las grabaciones de mis clases?

Mediante MCP, tu IA puede consultar las transcripciones disponibles de las grabaciones publicadas en UPC Class. Pídele un resumen, una explicación o las indicaciones del profesor: el análisis conserva el contexto y las marcas de tiempo para revisar la fuente. Necesitas acceso al curso y una transcripción disponible.

¿Campus reemplaza el campus virtual de mi institución?

No. Campus es una capa personal para consultar tu información académica desde herramientas que ya usas. El campus virtual de tu institución sigue siendo la fuente de los datos.

¿Qué instituciones funcionan hoy?

Hoy puedes conectar Blackboard UPC. Campus está diseñado para sumar institutos, universidades y otros campus virtuales; anunciaremos cada nueva compatibilidad antes de ofrecerla.

¿Puedo dejar de usarlo cuando quiera?

Sí. Puedes desconectar Blackboard y revocar el acceso desde Campus cuando lo necesites.

¿Necesito otra cuenta para el MCP?

No. Usa la misma cuenta Campus. Free incluye el panel, reseñas y 25 consultas de bienvenida en la web. Plus incluye 100 consultas diarias en la web y consultas ilimitadas mediante MCP con tu IA compatible. Campus CLI también ofrece una terminal de código abierto.

¿Es lo mismo que el paquete "campus-cli" de PyPI u otras apps de IA para estudiantes?

No. El paquete campus-cli de PyPI es un proyecto de Python no relacionado (gestión de archivos de notebooks Jupyter). Tampoco somos las plataformas de "IA para resolver tareas" que usan nombres parecidos. Este Campus es el paquete campus-cli de npm que conecta Blackboard UPC con ChatGPT y Claude vía MCP — el código fuente está en github.com/alejooroncoy/campus-cli.
